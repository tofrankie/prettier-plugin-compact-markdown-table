# Changelog

All notable changes to this package will be documented in this file.

## 0.0.1

> 2026-08-24

Forked from [myl7/prettier-plugin-compact-markdown-table](https://github.com/myl7/prettier-plugin-compact-markdown-table) `v0.1.0`. This fork differs from the upstream package in its `tableLayout` choices and default behavior.

- Added `compact` as the default layout, with one space around each cell.
- Added `compact-no-padding` for compact tables without cell padding.
- Kept `aligned` for Prettier's default aligned table layout.
